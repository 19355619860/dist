## 🏗️ 文件命名规则

### 详情页命名
```
格式: {col1拼音}-{col2拼音}-{col3拼音}-{col4拼音}-{id}.html

示例:
输入: col1=初中, col2=八年级, col3=语文, col4=人教版, id=1001
输出: chuzhong-banianji-yuwen-renjiaoba-1001.html
```

### 列表页命名
```
格式: {col1拼音}/{col2拼音}/{col3拼音}/{col4拼音}/[index.html|page-N.html]

目录结构示例:
dist/
├── index.html                          (全部教材首页)
├── page-2.html                         (全部教材第2页)
├── chuzhong/                           (初中)
│   ├── index.html                      (初中首页)
│   ├── page-2.html
│   ├── banianji/                       (初中/八年级)
│   │   ├── index.html
│   │   ├── yuwen/                      (初中/八年级/语文)
│   │   │   ├── index.html
│   │   │   ├── renjiaoba/              (初中/八年级/语文/人教版)
│   │   │   │   ├── index.html
│   │   │   │   └── page-2.html
```

## 🚀 构建执行流程图

```
开始
  │
  ▼
[用户运行: npm run build]
  │
  ▼
[启动 scripts/generate.js]
  │
  ▼
[1. 清空dist目录]
  │
  ▼
[2. 复制静态资源]
  ├─ peizhi/gongzonghao.jpg → dist/peizhi/
  └─ peizhi/tubiao.png → dist/peizhi/
  │
  ▼
[3. 加载Excel数据]
  │
  ├─ 读取 peizhi/keben_export.xlsx
  ├─ 解析为JSON数组
  └─ 得到 data[] (2000+条)
  │
  ▼
[4. 生成详情页循环]
  │
  ├─ 遍历 data[] 每一项
  │  │
  │  ├─ 计算文件名 (slugify + id)
  │  ├─ 渲染详情页模板
  │  ├─ 包装到layout模板
  │  ├─ 写入HTML文件
  │  └─ 记录到sitemap-detail
  │
  ▼
[5. 生成列表页组合]
  │
  ├─ 组合1: [] (全部教材)
  │  ├─ 分组数据
  │  ├─ 计算分页数
  │  ├─ 生成 index.html, page-2.html...
  │  └─ 记录到sitemap-list
  │
  ├─ 组合2: [col1] (学段)
  │  └─ (同上)
  │
  ├─ 组合3: [col1, col2] (年级)
  │  └─ (同上)
  │
  ├─ 组合4: [col1, col2, col3] (学科)
  │  └─ (同上)
  │
  └─ 组合5: [col1, col2, col3, col4] (版本)
     └─ (同上)
  │
  ▼
[6. 生成Sitemap]
  ├─ 写入 sitemap-list.xml
  └─ 写入 sitemap-detail.xml
  │
  ▼
[构建完成 ✅]
  │
  ▼
输出统计:
- 详情页: 2000+ 个
- 列表页: 500+ 个
- 总文件: 2500+ 个
- 总大小: ~230MB
  │
  ▼
结束
```
